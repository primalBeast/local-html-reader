Path display, copy menu, and release notes

d8b9def 2026-09-10
  • Viewer bar. Filename and search tools are on separate rows so nothing overlaps in a narrow window. The bar shows the relative path and filename from the documents root. Hover for the full absolute path.
  • Copy path. Right-click a filename in the tree or the right-pane title for Copy full path and Copy relative path.
  • Release notes. RELEASE-NOTES.html in the project root. Commit-and-push updates this file in the same commit.

Search history, side-by-side view, native TLS

103cfe5 2026-09-10
  • History lists every saved term. It opens on left-click or Down, hides while typing, and closes on blur or an outside click.
  • Up/Down highlight terms; Enter applies the highlighted term. A term is saved only when you leave the field with text, or press Enter in the box.
  • Tab / Shift+Tab cycle search boxes left-to-right and wrap.
  • side-by-side.html shows two app copies at http://127.0.0.1:8766/side-by-side.html (bookmark that URL, not the file on disk).
  • install.cmd runs uv sync --native-tls and sets UV_NATIVE_TLS=1 so corporate Windows certificate stores work. This is also fine on a home PC.

Live history across windows

217aff8 2026-09-10
  • Adding or deleting a search term updates every open window immediately.
  • Settings writes use a file lock so two instances cannot overwrite each other.
  • Changes are pushed over Server-Sent Events; other processes sharing the data dir pick them up from settings.json.
  • Each window still keeps its own open document and pane width.

  • Each recent-search row has a white × in a dark red circle to remove that term.

Search UI: spinner, clear, history

6c1e2ba 2026-09-10
  • Left-pane search shows a spinner and “Searching files…” while the tree is scanned.

Documentation browser

1beeec6 2026-09-09
  • Folder → Set root folder… chooses the documents root (absolute Windows path). HTML files stay on disk.
  • Left pane is a folder tree of .html / .htm files. The right pane is larger and shows the page.
  • Left search looks at visible document text, including collapsed Jazzy sections. Opening a hit expands the collapsed block and highlights the term.
  • Right pane has From list search (prefilled from the left) and independent Find in page.
  • The divider between panes is draggable; width is remembered.
  • Path sandbox: the API never serves files outside configured roots.
