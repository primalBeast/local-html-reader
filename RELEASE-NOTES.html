Local HTML Reader

Release notes for the local-first HTML documentation browser (local-html-reader). Newest changes first.

Word documents in the tree and viewer

unreleased 2026-09-17
  • .docx and .dotx files list in the tree and match left-pane search. Opening one renders it as HTML in the right pane, so Find in page, highlights, and Copy work the same as HTML and Markdown.
  • Requires mammoth (installed by install.cmd / uv sync). Legacy .doc files are not supported.

Splash shows on locked-down Windows

a9277b3 2026-09-16
  • The startup splash is an HTA opened with mshta, not a hidden PowerShell script. Corporate PCs often block .ps1 even with -ExecutionPolicy Bypass, and starting PowerShell hidden can hide the splash window too.

App icon, startup splash, and WebView launch fix

0f31065 2026-09-16
  • The WebView2 window uses a Local HTML Reader icon in the Windows taskbar instead of the Python icon.
  • start-webview.vbs / start-webview.cmd show a splash as soon as you launch, then close it when the main window is ready.
  • Startup no longer dies with “failed to start (code 1)” from passing icon= into pywebview’s create_window (that argument is GTK/Qt only). The icon is set on webview.start.

Regex search, history flags, and find-bar layout

8000103 2026-09-16
  • Aa / W / .* on every search box. Tree search, From list search, and Find in page honor match case, whole word, and regular expressions. Left-pane search shares those flags with From list search.
  • History. Each recent term stores those flags. Picking a row restores them (rows show Aa / W / .* when they apply). Turning an option on or off updates that term in history.
  • Find bar. The right pane keeps two boxes. Match counts always show, including 0 / 0. List-find n / n sits to the left of its box. Aa, W, .*, and the clear × sit inside the boxes.
  • Keyboard. With history open, arrows move through recent terms; with it closed, they move through matches. Esc hides the history list without clearing the query. Switching project clears the left search.
  • The Copy menu closes when you click the HTML page, the same way it does on Windows.

Scrollbar, PDF selection, and Copy popup

664dcce 2026-09-15
  • The right-edge window-resize grab no longer covers the viewer scrollbar, so you can scroll HTML, Markdown, and PDF panes.
  • PDF text can be selected and copied. Right-click a selection (or a page image) for a Copy menu. With no selection, Copy takes the word under the cursor. The same menu works in HTML and Markdown.

In-page HTML find uses srcdoc

a78bf30 2026-09-15
  • Right-pane search on HTML still failed after the Content-Disposition fix because find ran against a sandboxed iframe document (PDF search never did — it runs in the parent page).
  • HTML is now loaded with srcdoc so find walks the same-origin document body. List search and find-in-page should match text in the open HTML file.

HTML search works in the iframe again

4bf0a6b 2026-09-15
  • Edge was blocking HTML in the right pane the same way it blocked PDFs: Content-Disposition with a filename. HTML is now served inline with no filename, so list search and find-in-page can see the page text.
  • Document view URLs no longer append ?project=, which broke some HTML docs and in-page search.

Two windows, project menu, toolbar double-click

5074f1a 2026-09-15
  • Two instances. Open a second WebView2 window (run start-webview.vbs again) or another browser tab. Each window keeps its own project; switching project in one does not change the other.
  • Project menu. Click outside the menu to close it. Click a project name to switch to that project and close the menu.
  • Toolbar. Double-click the toolbar or the grab bar to maximize/restore. Drag starts after a small move so it does not steal the double-click. The top resize strip is thinner, matching Local Issue Tracker.

PDF zoom, tree paging, no HTML-to-PDF flash

c735192 2026-09-15
  • PDF zoom. Opening a PDF after HTML fits one page to the pane height. Ctrl+wheel zooms; the page stays centered and search highlights stay on the glyphs. Switching PDF to PDF keeps that zoom.
  • Tree keys. Home / End select the first / last file and Home scrolls to the very top of the list. PageUp / PageDown select the file at the top / bottom of the visible pane.
  • HTML to PDF. The previous HTML page stays visible with the faint spinner until the PDF is ready, so the pane does not go black.

PDF loading spinner

6d8b685 2026-09-14
  • While the next PDF loads, a small 75%-transparent spinner sits in the center of the right pane over the current page.

PDF viewer, search, and layout

9b5e135 2026-09-14
  • PDF.js viewer. The right pane renders PDFs with a text layer so From list search and Find in page work. Highlights are translucent overlays on the glyphs. The worker is served as JavaScript (Windows was sending .mjs as text/plain and Edge blocked it).
  • Encrypted PDFs. Left-pane search decrypts empty-password AES files (needs cryptography). That is why TD confirmations such as 044147J were missing before.
  • Fit and resize. Pages follow the right-pane width. Live resize scales in place (no black flash); after you pause, it re-renders. Shrinking keeps the page centered. Switching PDFs keeps the old page until the new one is ready.
  • Scrollbars. WebView2 resize handles no longer steal the layout row, so the tree and PDF scroll inside the window instead of drawing below it.

PDFs open in the right pane

ff21d92 2026-09-14
  • PDFs were loading in a sandboxed iframe, so Edge showed This page has been blocked by Microsoft Edge.
  • The right pane now shows PDFs instead of Edge blocking a sandboxed iframe. HTML pages stay sandboxed.
  • In-page find applies to HTML and Markdown. PDF find landed in the following release.

Projects, PDF/Markdown, and WebView2

2ecf954 2026-09-14
  • Projects. Named projects each have their own folder list. Check or uncheck folders, add more, and right-click a project to rename or delete. Daily backups go under projects\<slug>\backups\YYYY-MM-DD.
  • PDF and Markdown. The tree and search include .pdf, .md, and .markdown alongside HTML. Markdown is rendered in the viewer; PDF search uses extracted text.
  • Copy folder path. Right-click a folder in Folders in this project for full and relative path copy.
  • WebView2. start-webview.vbs / uv run lhr serve --webview opens a frameless Edge window. Toolbar ─ □ ✕, drag, edge resize. Maximize fills the work area (taskbar stays visible); F11 is fullscreen; F5 reloads.
  • Hidden console. start.vbs and start-webview.vbs start already minimized (no console flash). Restore Local HTML Reader from the taskbar for logs.
  • Settings writes retry on OneDrive Access denied. Deleting a project removes project.json first so the name disappears even if backup files are locked.

Search on Enter or blur; narrower find boxes

3eb495c 2026-09-11
  • Document list, From list search, and Find in page no longer search on each keystroke. A search runs when you press Enter or leave the field.
  • Right-pane search boxes stay centered, cap at a modest width, and shrink if the pane is too narrow.

Path display, copy menu, and release notes

d8b9def 2026-09-10
  • Viewer bar. Filename and search tools are on separate rows so nothing overlaps in a narrow window. The bar shows the relative path and filename from the documents root. Hover for the full absolute path.
  • Copy path. Right-click a filename in the tree or the right-pane title for Copy full path and Copy relative path.
  • Release notes. RELEASE-NOTES.html in the project root. Commit-and-push updates this file in the same commit.

Search history, side-by-side view, native TLS

103cfe5 2026-09-10
  • History lists every saved term. It opens on left-click or Down, hides while typing, and closes on blur or an outside click.
  • Up/Down highlight terms; Enter applies the highlighted term. A term is saved only when you leave the field with text, or press Enter in the box.
  • Tab / Shift+Tab cycle search boxes left-to-right and wrap.
  • side-by-side.html shows two app copies at http://127.0.0.1:8766/side-by-side.html (bookmark that URL, not the file on disk).
  • install.cmd runs uv sync --native-tls and sets UV_NATIVE_TLS=1 so corporate Windows certificate stores work. This is also fine on a home PC.

Live history across windows

217aff8 2026-09-10
  • Adding or deleting a search term updates every open window immediately.
  • Settings writes use a file lock so two instances cannot overwrite each other.
  • Changes are pushed over Server-Sent Events; other processes sharing the data dir pick them up from settings.json.
  • Each window still keeps its own open document and pane width.

Documentation browser

1beeec6 2026-09-09
  • Folder → Set root folder… chooses the documents root (absolute Windows path). HTML files stay on disk.
  • Left pane is a folder tree of .html / .htm files. The right pane is larger and shows the page.
  • Left search looks at visible document text, including collapsed Jazzy sections. Opening a hit expands the collapsed block and highlights the term.
